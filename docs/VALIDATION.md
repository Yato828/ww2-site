# Проверка проекта

Дата обновления: **29 октября 2026 года**.

Проверена версия после удаления функции сохранения историй, расширения коллекции до 20 статей, добавления видеотеки и 16 новых фотографий и репродукций документов. Всего в проекте 24 изображения; у каждой статьи отдельное превью.

## Команды

```bash
npm run build
npm run lint
npm run test
npm run test:e2e
```

| Проверка | Фактический результат |
| --- | --- |
| `npm run build` | Пройдено: TypeScript и производственная сборка Vite |
| `npm run lint` | Пройдено без ошибок |
| `npm run test` | 11 тестов в 4 файлах пройдено |
| `npm run test:e2e` | 10 основных сценариев Chrome пройдены перед публикацией |
| `npm run test:e2e -- --grep 'postwar period'` | Пройден дополнительный сценарий переноса «После войны», 3,1 секунды |

В одном предварительном запуске внешний сервер тайлов OpenStreetMap не ответил за 15 секунд. Отдельная повторная проверка и окончательный полный запуск прошли, включая загрузку настоящей картографической подложки. Проверки не подменяют её заглушкой.

Vite сообщает о главном JS-файле размером около 527 kB до gzip (163 kB после gzip), превышающем рекомендованный порог 500 kB. Сборка завершена успешно; полевые показатели производительности не измерялись.

## Что проверяется

Модульные и компонентные тесты проверяют исторические данные, наличие локальных фотографий и их атрибуцию, уникальность превью статей, связи видеоматериалов со статьями, подключение плеера только после нажатия, внешнюю ссылку второго выпуска, прохождение викторины и выбор события хронологии.

Браузерные сценарии запущены в системном Google Chrome. Проверены восемь основных разделов, все 20 страниц статей, локальные фотографии, поиск по полному тексту, фильтры, связанные видеоматериалы, маркеры карты и викторина. Проверены ширины 320, 390, 768 и 1440 px, отсутствие горизонтального переполнения и навигация мобильного меню. Старый адрес `/archive` перенаправляет к историям; ссылки на удалённую функцию отсутствуют.

Для фотографии «Первый день войны» проверены `object-fit: contain`, увеличенная высота на компьютере и сохранение исходного соотношения сторон на телефоне. Все показанные локальные изображения проходят проверку загрузки. Превью статей имеют единый формат 4:3 с `object-fit: cover`; основные изображения статей и хронологии используют `contain` и остаются целыми.

Надпись «После войны» в боковой колонке имеет отдельный размер шрифта и переносится только между словами. Браузерная проверка измеряет целостность обоих слов и попадание в границы колонки при ширинах 701, 768 и 1440 px; на ширине 320 px проверяется мобильное представление. При изменении окна тест ожидает перерисовки адаптивных стилей.

## Артефакты

Снимки страниц сохраняются в `test-results/desktop-*.png` и `test-results/mobile-*.png`. Карточки после выравнивания визуально проверены по `home-story-previews.png` и `catalog-story-previews.png`: единый формат 4:3, без боковых и верхних полей; портреты имеют индивидуальное положение кадра. Трассировки сохраняются при падении сценария. Код проверок находится в `src/**/*.test.ts`, `src/**/*.test.tsx` и `e2e/museum.spec.ts`.

## Границы проверки

Полный независимый аудит WCAG 2.2 AA, измерение Core Web Vitals в реальных условиях и испытания на физических устройствах не проводились. Автоматическая проверка интерфейса не означает сертифицированного соответствия стандарту.

Проверки в этом протоколе выполнены локально. Карта и внешние источники зависят от доступности сторонних сервисов. Для видео проверены официальные страницы, адрес встроенного плеера и поведение интерфейса. Непосредственное воспроизведение роликов не подтверждалось: браузерный тест блокирует запрос к VK и проверяет наличие запасной ссылки на музей.
