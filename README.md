# Нить памяти

**Истории, которые связывают поколения.**

Образовательный цифровой музей исторической и семейной памяти Беларуси. Приложение связывает документальные очерки о Великой Отечественной войне, хронологию, памятные места и разговор о связи поколений.

Проект подготовлен для номинации «Связь поколений: мы помним» конкурса «ПАТРИОТ.by — 2026». Текст официального положения конкурса не предоставлен. Описанные здесь цели и решения — авторский замысел, а не утверждение об официальных критериях оценивания.

## Цель и актуальность

История семьи часто хранится в неподписанных фотографиях, письмах и устных рассказах. Без контекста и резервных копий такие свидетельства легко потерять. Цель проекта — помочь посетителю перейти от знакомства с историей страны к внимательному разговору с близкими и самостоятельному исследованию семейных документов.

Визуальная нить соединяет времена, документы и действия человека: **они пережили → они сохранили → мы помним**. Центральная тема — связь поколений через сохранение достоверной памяти.

## Задачи

- Представить исторические сведения с конкретными ссылками на источники.
- Показать человеческий опыт за датами и памятными местами.
- Дать инструменты исследования: фильтры, поиск, хронологию и карту.
- Помочь понять значение семейных фотографий, документов и рассказов.
- Заинтересовать молодую аудиторию историей через вопросы с объяснениями.
- Обеспечить адаптивный интерфейс, клавиатурное управление и бережное отношение к пользовательским данным.

## Для кого

Для школьников и студентов, семей, педагогов, руководителей музейных и краеведческих объединений, а также посетителей, начинающих исследование семейной истории. Проект подходит для самостоятельного знакомства и демонстрации на занятии или музейном экране.

## Что умеет сайт

| Раздел | Адрес | Возможности |
| --- | --- | --- |
| Главная | `/` | Редакционное знакомство с проектом, архивный первый экран, переходы к историческим материалам |
| Истории людей | `/stories` | 20 биографических и тематических очерков, шесть тематик, поиск по полному тексту, фильтры, пустая выборка; отдельные материалы с хронологией, источниками и связанными историями |
| Лента времени | `/timeline` | Выбор периода и события, раскрытие подробностей, переход к соседним событиям; горизонтальная шкала на широком экране и вертикальная на телефоне |
| Карта памяти | `/map` | Настоящая карта Leaflet/OpenStreetMap, пять мемориальных мест, маркеры с карточками, поиск, фильтр по типу и самостоятельные страницы объектов |

| Видеотека | `/videos` | Два музейных видеоматериала: плеер по нажатию и переход к официальному выпуску; пояснения и связанные статьи |
| Что мы помним? | `/quiz` | Десять вопросов, выбор и проверка ответа, объяснения и источники, прогресс, итог, разбор и повторное прохождение |
| Источники и о проекте | `/about` | Замысел, устройство приложения, приватность, исторические источники, авторы и лицензии изображений |

Страницы материалов открываются по `/stories/:id`, памятных мест — по `/places/:id`. Неизвестный адрес показывает страницу с предложением вернуться в музей.

### Данные и приватность

Сайт не принимает пользовательские истории и фотографии, не требует регистрации и не подключает собственную аналитику или рекламу. Историческая коллекция входит в сборку. Поиск, фильтры и ответы викторины обрабатываются в браузере.

Подложка карты загружается с OpenStreetMap; при открытии карты браузер обращается к внешнему сервису. Плеер VK загружается только после нажатия пользователя; при этом действуют правила внешней площадки. Второй видеовыпуск и источники открываются на сайтах соответствующих учреждений. Прежний адрес `/archive` перенаправляет к историям. Ранее записанные данные удалённой функции приложение не читает и не стирает.

## Особенности реализации

Музейная палитра, типографика Cormorant Garamond и Manrope, светлые и тёмные главы, анимированная нить и редакционная композиция поддерживают содержание. Исторические фотографии имеют подписи; независимые снимки не представлены как история одной семьи.

Маршруты разделены на загружаемые по требованию модули. Изображения и шрифты входят в поставку приложения. Motion учитывает системную настройку уменьшения движения. Предусмотрены семантические элементы, доступный поиск, состояния фокуса, ссылка перехода к основному содержимому и перенос фокуса при навигации.

У основных маршрутов обновляются `title`, `description` и Open Graph. Это клиентское SPA: метаданные, меняющиеся после исполнения JavaScript, доступны не всем поисковым и социальным роботам. Для полного индексирования отдельных материалов потребуется предварительный рендеринг или SSR.

## Локальный запуск

Нужны Node.js 22.12 или новее и npm. В каталоге проекта выполните:

```bash
npm install
npm run dev
```

Vite выведет адрес сервера, обычно `http://127.0.0.1:5173`. Открывайте этот адрес в браузере. Запуск `index.html` напрямую через `file://` не поддерживается.

Переменные окружения, API-ключи и серверная настройка для локального запуска не нужны. Для первой установки зависимостей, подложки карты и открытия внешних источников требуется интернет.

## Сборка и проверки

```bash
npm run build
npm run lint
npm run test
npm run preview
```

`build` сначала проверяет TypeScript, затем создаёт каталог `dist/`. `preview` обслуживает готовую сборку, обычно на `http://127.0.0.1:4173`. Тесты проверяют целостность исторических данных, прохождение викторины и переходы хронологии. Этот список команд является инструкцией запуска, а не протоколом успешного выполнения.

Протокол проверки актуальной версии: [docs/VALIDATION.md](docs/VALIDATION.md).

### Браузерные сценарии и снимки экранов

В `e2e/museum.spec.ts` находятся проверки основных маршрутов, локальных изображений, карты, фильтров, истории браузера, фотографий и полного прохождения викторины. Адаптивность проверяется на ширинах 320, 390 и 768 px; настольный сценарий использует 1440 px.

```bash
npm run test:e2e
```

Конфигурация Playwright использует **установленный в системе Google Chrome** (`channel: 'chrome'`) в headless-режиме. Для запуска необходим установленный Chrome; отдельный браузер Playwright эта конфигурация не загружает. Тесты сами запускают Vite на `http://127.0.0.1:4178` либо используют уже работающий на этом порту сервер при локальном запуске. Сценарий загрузки подложки карты требует доступности OpenStreetMap.

При выполнении создаются снимки экранов:

- `test-results/desktop-home.png`, `desktop-stories.png`, `desktop-timeline.png`, `desktop-map.png`, `desktop-generations.png`, `desktop-quiz.png`, `desktop-about.png`;
- `test-results/mobile-320-home.png` и `mobile-320-stories.png`;
- аналогичные пары с `mobile-390-` и `mobile-768-`.

Снимки помогают оценить внешний вид и не являются доказательством полного аудита доступности. Трассировки сохраняются при падении сценария. Результаты последнего запуска определяются выводом соответствующей команды; документация не подменяет финальный протокол проверок.

## Развёртывание

Приложение предназначено для статического хостинга в корне домена. Репозиторий: [Yato828/ww2-site](https://github.com/Yato828/ww2-site). Целевой проект Vercel — `ww2-hero`, адрес — [ww2-hero.vercel.app](https://ww2-hero.vercel.app).

### Vercel

1. Подключите репозиторий `Yato828/ww2-site` к проекту `ww2-hero`; производственная ветка — `main`.
2. Настройки заданы в `vercel.json`: Vite, установка `npm ci`, сборка `npm run build`, выходной каталог `dist`.
3. В проекте используется Node.js 24. Переменные окружения не требуются.
4. Сохраните правило в `vercel.json`: оно направляет клиентские маршруты на `index.html`.
5. После публикации откройте вложенный маршрут напрямую и обновите страницу.

### Netlify

1. Подключите Git-репозиторий или подготовьте каталог `dist` локально.
2. Для сборки из исходников задайте команду `npm run build`, каталог публикации `dist` и совместимую версию Node.js.
3. Файл `public/_redirects` автоматически попадает в сборку и обеспечивает SPA fallback.
4. При ручной загрузке отправляйте весь `dist`, включая `_redirects`, изображения и `assets`.
5. Проверьте прямые переходы на `/timeline` и `/stories/brest-defenders`.

Для другого статического хостинга настройте отдачу существующих файлов и fallback неизвестных клиентских путей на `index.html`. При размещении в подкаталоге потребуется согласованно настроить Vite `base`, `BrowserRouter basename` и абсолютные пути изображений.

## Источники, фотографии и лицензии

Историческая основа хранится в `src/data/history.ts`, `peopleStories.ts` и `documentStories.ts`. Видеоматериалы описаны в `src/data/videos.ts`. Каждый очерк, событие, памятное место и вопрос ссылается на конкретную страницу. Использованы материалы Белорусского государственного музея истории Великой Отечественной войны, мемориальных комплексов «Брестская крепость-герой» и «Хатынь», Жлобинского музея, архивных и других профильных учреждений. Подробный реестр — в [docs/SOURCES.md](docs/SOURCES.md) и разделе `/about`.

Очерки — редакционные образовательные тексты; они не выдаются за подлинные письма, цитаты или реконструированные биографии. Архивные и современные фотографии явно различаются. Материалы взяты с Wikimedia Commons с указанием автора, оригинала и обозначенных там условий: общественное достояние, CC0, CC BY либо CC BY-SA в соответствующей версии.

Для 20 статей используются 20 разных фотографий и репродукций документов. Всего в проекте 24 изображения. Превью статей имеют единый формат 4:3 без пустых полей; для портретов и памятников настроено положение кадра. Внутри статей и хронологии снимки показаны целиком, включая портретную фотографию Брестской крепости. Реестр новых изображений — [docs/ADDITIONAL_PHOTOS.json](docs/ADDITIONAL_PHOTOS.json).

При повторном использовании сохраняйте атрибуцию, ссылку на оригинал и лицензию. Для производных изображений соблюдайте условия конкретной лицензии, включая ShareAlike там, где она применима. В интерфейсе используется монохромное отображение; исходные файлы сохраняются в `public/images`.

Картографическая подложка: © OpenStreetMap contributors; [сведения об авторстве и условиях использования](https://www.openstreetmap.org/copyright) доступны у поставщика. Шрифты устанавливаются из пакетов `@fontsource`; условия поставляются в составе соответствующих пакетов.

Лицензия на собственный исходный код проекта отдельно не назначена. Лицензии сторонних библиотек, шрифтов и иллюстраций действуют на соответствующие материалы и не подменяют друг друга.

## Ограничения и развитие

- Коллекция включает 20 статей, два видеоматериала и пять памятных мест. Это образовательный маршрут, не исчерпывающий каталог событий или мемориалов Беларуси.
- Для тайлов OpenStreetMap требуется сеть. Описания, фотографии и список мест входят в сборку. Отдельный offline/PWA-режим не реализован.
- Локальная адаптивная реализация и доступные элементы интерфейса не заменяют независимый аудит доступности и тестирование на физических устройствах.
- Социальные предпросмотры отдельных маршрутов ограничены клиентским рендерингом.

Направления развития: пополнение проверенной коллекции, редактура музейными специалистами, улучшение поиска, новые образовательные маршруты и предварительный рендеринг страниц.
